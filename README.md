## Deployment

Push to "main" → GitHub Actions → website.

That's basically it.

## Usage

To add articles, go to `all_collections/_posts`.

Fill in your personal information in `_config.yml` and `_data/author.yml`.

---

Run
```bash
bundle install
```
to install dependencies.

Run
```bash
bundle exec jekyll serve
```
to test locally.

For GitHub Pages deployment, please allow loading `link_filter.rb` under `_plugins` to enable friend link rendering.
