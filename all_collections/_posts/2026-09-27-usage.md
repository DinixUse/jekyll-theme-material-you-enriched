# 用法

关于友链添加请查看[友链语法演示](../友链语法演示)。

关于 Markdown 语法请查看[Jekyll Markdown](../jekyll-markdown)。

文章增添请进入 `all_collections/_posts`

在 `_config.yml` 以及 `_data/author.yml` 填写你的个人信息。

可以将 `assets/css/dark.css` 中的配色替换为你的配色方案。

---

执行
```bash
bundle install
```
安装依赖。



执行
```bash
bundle exec jekyll serve
```
在本地运行测试。

对于 GitHub Pages 部署，请允许加载 `_plugins` 下的 `link_filter.rb` 以允许友链渲染。
